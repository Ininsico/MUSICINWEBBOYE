# 🎹 MI AMOR: Imperial 88-Key Studio
### *The Definitive Cinematic Instrumental Sanctuary*

**MI Amor** is an industrial-standard, browser-integrated musical studio engineered for high-fidelity performance. It features a clinically precise **Imperial 88-Key Grand** piano, a Zimmer-grade **Orchestral Drone Engine**, and a tactical mapping system for full-spectrum accessibility.

---

## 🏛️ 1. THE INSTRUMENT: Imperial 88-Key Grand
The crown jewel of the studio is the zero-scroll, 88-key physical grand simulation (A0 to C8).
*   **3D Ebony & Rosewood Geometry**: Engineered with weighted ivory textures and glossy accidental finishes for a premium tactile feel.
*   **Zero-Striction "Instant" Reset**: A 0ms mechanical response engine. No sliding, no lag—keys snap back instantly upon release.
*   **Cinematic "Halo" Visuals**: Musical events trigger ethereal light-burst highlights instead of basic flat colors.
*   **Subtractive Felt Audio Context**: Low-passed (420Hz) triangle/sine hybrid oscillators with a hammer-impact simulator (50ms noise burst) and a 10s master limiter to prevent polyphonic distortion.

Perform across all 88 notes without scrolling. The piano uses a specialized surgical tri-row letter layout:

## 🚀 3. PERFORMANCE COMMANDS & HUD
*   **Play Song (Masterpiece Mode)**: Initiates the 4-minute, 200+ note cinematic arrangement of *Interstellar (Stay)*.
*   **Stop Session (Atomic Purge)**: Instantly disconnects and kills all oscillators. A clinical "kill switch" for absolute silence.
*   **Full Screen (Concert Sanctuary)**: Transitions to a 100vw isolation mode for professional, distraction-free performance.
*   **Rhythmic HUD (Score Preview)**: A Surgical "Next 5" musical event strip located below the ivory keys for real-time situational awareness.

## 🔊 4. AUDIO LOGIC & PEDALRY
*   **Sync Studio Gate**: Browser security requires a manual initialization. Tap the **Speaker Icon** on entry to engage the high-fidelity sound engine.
*   **Spacebar (Damper Pedal)**:
    *   **Hold**: Activates the 1.5s Cinematic Zimmer Echo (High Sustain).
    *   **Release**: Clamps all notes with a 0.5s dry release for tight melodic runs.
*   **Zimmer Drone Sync**: The background atmospheric drone is integrated directly into the piano's synchronized AudioContext for zero digital collision.

## ⚙️ 6. SETUP & INSTALLATION
1.  **Clone the Repository**.
2.  **Environment Sync**: Create a `.env.local` in `/frontend` with your Clerk credentials:
    ```env
    VITE_CLERK_PUBLISHABLE_KEY=your_key_here
    ```
3.  **Dependencies**:
    ```bash
    npm install
    npm run dev
    ```
